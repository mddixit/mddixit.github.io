Put project photos here, one folder per project, named after the project's "slug"
in assets/projects.js. For example:

  images/manta-ray/1.jpg
  images/manta-ray/2.jpg
  images/manta-ray/cover.jpg   (optional main photo; set cover: "images/manta-ray/cover.jpg")

Filenames must match what's listed in projects.js exactly (including .jpg vs .png and capital letters).
Photos listed in projects.js but not uploaded yet are hidden on the live site automatically.
Tip: resize photos to about 1600px wide before uploading so pages load fast.
